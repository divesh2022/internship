# Internship — Project Portfolio

A collection of project work from an internship, containing three independent projects: a Disaster Management study (with GIS maps, reports and presentation), a Drone simulation/analysis project, and a Rocketry project. This repository stores reports, notebooks, plots and supporting media produced during the internship.

## Projects at a glance
- Disaster Management Project
  - Heat-action case studies, GIS temperature heatmaps, a full project report and presentation.
  - Artifacts: PDFs (case studies), high-resolution GIS heatmap PNGs, project report PDF, PPTX/PDF presentation, photographs.
- Drone Project
  - Jupyter notebooks, simulation plots and tuning/analysis artifacts (figure-eight simulation, PID tuning plots, boat guidance plots) and a project report.
  - Directory structure groups completed notebooks/code, plots and the final report.
- Rocketry Project
  - Folder present at top level — inspect for notebooks, code and report files (contents not detailed here).
